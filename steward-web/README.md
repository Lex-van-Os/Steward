# Steward web interface
Steward web is the front door to Steward, where you catalogue your collection, add tasting notes, and browse the recommendations Steward generates for you.

## What it is
Steward web offers an user friendly interface to interact with Steward. It's where a personal collection of wine, whisky, cigars, and pipe tobacco is catalogued, tasting notes and ratings are added, and pairing recommendations are browsed — with the reasoning behind each suggestion presented in a way that's easy to follow, rather than a plain list of results.

## How it works
1. **Catalogue and notes are managed here** — adding bottles, cigars, and tobacco blends, along with personal tasting notes and ratings, all sent to the API.
2. **Recommendations are fetched from the API**, which are generated by the AI engine and grounded in the user's own data.
3. **Explanations are surfaced alongside suggestions**, so pairings are presented with their reasoning rather than as an opaque result.
4. **It runs as the front-facing service** of Steward, behind a reverse proxy, self-hosted on a single machine.
